# ALACENA v8

Aplicación familiar para compras, despensa, menú, recetas, tickets, reportes e inteligencia artificial.

## Publicación

El proyecto está preparado para GitHub + Netlify.

- Build: `npm run build`
- Carpeta publicada: `dist`
- Funciones: `netlify/functions`

Las credenciales deben mantenerse como variables de entorno en Netlify. No deben guardarse dentro del repositorio.

Consulta `INSTRUCCIONES_PARA_GITHUB.txt` para subir una actualización sin usar VS Code.
